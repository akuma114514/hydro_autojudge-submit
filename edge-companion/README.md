# Edge 伴随扩展

此扩展支持将当前洛谷普通题目链接（`https://www.luogu.com.cn/problem/P1001` 等）交给 VS Code 导入公开题面和样例；无需向浏览器添加洛谷页面脚本权限，VS Code 会自行读取公开题目页。洛谷仍需手动提交。

自动提交只为 `https://frp-fan.com:36387` 的普通题目工作，通过本机 `127.0.0.1` 桥接从 VS Code 获取已通过全部公开样例的 C++17 源码。它使用 Edge 中已登录的题目页提交，不读取或传递密码、Cookie。

## 首次安装与配对

1. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”，选择“加载解压缩的扩展”，指向本目录 `edge-companion`。
2. 先按[主 README](../README.md)安装 VS Code 插件、配置编译器并打开已保存的 `.cpp` 文件。保持 VS Code 打开；仅使用网页导入时无需开启自动提交。
3. 在 VS Code 执行“Hydro: 复制 Edge 配对信息”。点击 Edge 扩展图标，将剪贴板内容完整粘贴进配对框，点击“保存并检查”。配对信息包含本机访问令牌，请勿公开分享。
4. 在 Edge 中登录 Hydro，并打开准备提交的**同一道题目**页面。由于站点证书链不受信任，浏览器必须已经允许你访问该站点。
5. 如需自动提交，先在 VS Code 设置中开启 `hydroSamples.autoSubmit`，保存代码，再执行“Hydro: 一键运行自测”。全部样例通过后，插件会排队；伴随扩展最多约 30 秒后检查待提交任务。成功时 VS Code 显示评测记录链接。
6. 网页一键导入：在 VS Code 中打开一个已保存的 C++ 文件，在 Edge 打开 Hydro 或洛谷普通题目页，点击伴随扩展图标，再点击“将当前题目导入 VS Code”。若当前文件已有样例记录，VS Code 会询问是否覆盖。

自动提交默认关闭。该扩展不会在没有对应题目页的情况下提交；不会在本地样例失败时提交。遇到提交结果不明确的情况，不自动重复提交，以免产生重复评测记录。

## 当前限制

- 自动提交仅支持上面的自建站与 C++17 普通题目。比赛、作业题目没有纳入范围。
- 已在用户的 Edge 会话中完成一次真实提交；本地样例通过仍不代表网站评测 AC。
- 伴随扩展只在题目页已打开时领取代码。领取后若浏览器或 VS Code 中断，任务不会自动重复提交。
- 提交后最多等待约 30 秒读取评测得分；仍未出分时，VS Code 显示评测记录链接供稍后查看。

更新后请在 `edge://extensions` 中点击该扩展的重新加载按钮，并更新 VS Code 插件。保持 VS Code 打开且当前编辑器为已保存的 `.cpp` 文件，再在洛谷题目页点击“将当前题目导入 VS Code”。
